f127-load

Design a system

Pick what you want and this works out the rest, then hands you a system.json. Give that file to ./f127 run in a terminal and the system gets built. Nothing runs here.

1The box

One micelle sits in the box, and only the 34-chain structure ships, so the box edge is the size to choose. It decides how much water surrounds the micelle, and water is most of the cost.

2Ions

Set as many as are wanted. Zero leaves a salt out. The button fills in extracellular fluid.

3The solute

Only molecules with a topology are listed. For anything else, put the output of CHARMM-GUI Ligand Reader and Modeler into library/<name>/.

5Where it starts

Two simulations, not one split in half. Each is built with the amount below, so 4 and 4 means two boxes holding four molecules each, one starting in the water and one starting in the hollow. They match by default, which is what makes the pair comparable; the only reason to part them is that the hollow holds far fewer than the water around it. Counts, whatever unit the amount above was given in, because the hollow's limit is a count.

Where these numbers come from

The weight fraction follows from the box edge: 34 chains in a 17.0 nm box is 14.5 wt%, in a 24.8 nm box 4.7 wt%.

Core volume goes as the number of chains, so the core radius goes as its cube root, scaled from the 3.99 nm measured on the shipped structure. The corona is one poly(ethylene oxide) block long however many chains there are, so its 3.0 nm is carried across rather than scaled.

The atom count is scaled from 488,823 atoms for 34 chains in a 17.0 nm box.

The limit on the inside route is the radius the solute occupies when packed together, its vdW volume times 1.4, against the 1.5 nm hollow in the shell template.

Using a size other than the one that ships

Only 34 chains ship with the tool. For a smaller box, remove water from an equilibrated box with scripts/densify.py and use that structure as the host, rather than shrinking the box around the structure.
