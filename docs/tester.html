다른 컴퓨터에서 도는지 한 번만 확인해 주세요

F127 미셀에 pyrene을 넣은 GROMACS 시스템을 자동으로 만들어 돌리는 도구입니다. 제 컴퓨터가 아닌 곳에서도 그대로 되는지, 그리고 그 GPU에서 하루에 몇 ns가 나오는지가 알고 싶은 전부입니다. GPU면 1시간 안쪽, 인터넷은 필요 없습니다.

필요한 것Linux 노드, GROMACS 2019 이상, python3 + numpy
필요 없는 것인터넷, 관리자 권한, MDAnalysis (분석 단계에만 쓰임)
걸리는 시간RTX 3090 기준 확인 실행 40분 안팎, 사람 손은 5분. 지금까지 보고된 속도: RTX 5090 106 ns/day, RTX 3090 43, RTX 3070 39

  1. 압축을 풀고 폴더에 들어갑니다

    tar xzf f127-load_260916.tar.gz
cd f127-load

    모든 명령은 이 폴더 안에서 ./f127 … 로 실행합니다. 다른 곳에서 부르려면 /전체/경로/f127-load/f127 … 처럼 절대경로로 씁니다.

  2. 환경 점검

    ./f127 check
    이렇게 나오면 정상 
    [ ok ] GROMACS 2022.3  (/usr/local/gromacs/bin/gmx)
[ ok ] GPU: NVIDIA GeForce RTX 3090  (gmx built with CUDA)
[ ok ] Python 3.10  (python3)
[warn] MDAnalysis is not installed, so `python3` can build and run but not analyse.
       …  ← 이 경고는 무시해도 됩니다
[ ok ] NumPy 1.26.4
[ ok ] wrote /…/f127-load/compat.json
    no GROMACS binary on PATH 라고 나오면 → source /usr/local/gromacs/bin/GMXRC 한 뒤 다시.
    Permission denied 면 → chmod +x f127.

  3. 설정 파일 system.json 을 하나 만듭니다

    세 방법 중 아무거나. 결과 파일은 같습니다.

    A. 브라우저에서 (원래 설명한 방법)docs/build.html 을 브라우저로 열고 → 아래쪽까지 원하는 것을 고른 뒤 → Download system.json. 파일은 ~/Downloads 에 떨어지고, 옮기지 않아도 됩니다. 4번에서 그 경로를 그대로 적으면 됩니다.
    B. 터미널에서./f127 new 를 치면 몇 가지를 묻고 system.cfg 를 써 줍니다. 4번에서 system.json 대신 system.cfg 를 적습니다.
    C. 그냥 복사아래 내용을 system.json 으로 저장. 이 파일이 제가 확인해 본 기본값입니다. 
    {
  "chains": 34,
  "box": 18.0,
  "salts": {"NaCl": 0.154},
  "guest": "pyrene",
  "count": 20,
  "route": "solution"
}

  4. 실행하고 ns/day 를 읽습니다

    성능만 보면 되므로 평형 0.2 ns + 생산 1 ns 로 줄여서 돌립니다. 3090이면 40분 안팎입니다. 시스템 만들기(용매 채우기, 이온 넣기, 최소화)가 먼저 몇 분 걸립니다.

    ./f127 run ~/Downloads/system.json 1 --npt 0.2

    터미널을 닫아도 계속 돌게 하려면:

    nohup ./f127 run ~/Downloads/system.json 1 --npt 0.2 > run.out 2>&1 &
tail -f run.out
    이렇게 나오면 정상 
      plan: equilibrate 0.2 ns, then produce 1 ns
        about 0.7 h at 43 ns/day, measured on one RTX 3090
=== run_pyrene_solution  (20 x pyrene, solution, box 18.0 nm, NaCl:SOD:CLA:541:541:1)
  using GROMACS version: 2022.3
  …
  npt 0.2 ns = 100000 steps
  final box:   17.89053  17.89053  17.89053
  1 ns = 500000 steps
Performance:       43.118        0.557   ← 첫 숫자가 ns/day 입니다
done.

    결과는 명령을 친 자리에 run_pyrene_solution/ 폴더로 남습니다. 성능 줄은 run_pyrene_solution/prod.log 맨 아래에도 있습니다.

    시간이 없으면 ./f127 test ~/Downloads/system.json 만 해 주셔도 됩니다. 전 단계를 아주 짧게(0.02 + 0.05 ns) 통과만 시켜서 "여기서 도는가"에는 답이 되고, ns/day 는 부정확합니다.

  5. 알려 주실 것

    • ./f127 check 출력 전체 (복사해서 붙여 주세요)
    • Performance: 줄 한 줄
    • 노드 이름과 GPU (hostname; nvidia-smi -L)
    • 안 됐으면: 화면의 마지막 20줄, 그리고 메시지가 가리키는 로그 파일 (grompp_*.log, em.out, npt.out, prod.out 중 하나)

막히기 쉬운 곳

증상원인과 해결
no GROMACS binary on PATH로그인 셸에 gmx가 없음. source /usr/local/gromacs/bin/GMXRC 후 다시 실행. 다른 경로면 GMX=/경로/gmx ./f127 …
[failed] no such config경로 오타. ls ~/Downloads/*.json 으로 파일 이름 확인. 브라우저에서 저장 이름을 바꿨으면 그 이름으로.
-nb gpu was requested, but … built without GPU support그 gmx가 CPU 전용 빌드. 자동으로 피하도록 되어 있지만 뜨면 MDRUN_OPT="-ntmpi 1 -ntomp 16" ./f127 run …
다른 GROMACS 버전 경고 [warn] another GROMACS is installed정보용. 처음 잡힌 gmx 하나로 끝까지 가므로 문제 없음.
Fmax is large 경고 뒤 계속 진행최소화는 됐다는 뜻. 그대로 두면 됩니다.
Mac에서 build.html 이 안 열림다운로드 파일 보안 경고. 우클릭 → 열기, 또는 브라우저 창에 파일을 끌어다 놓기.
